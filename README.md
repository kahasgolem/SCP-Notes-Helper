# SCP Notes Helper

Browser application for reading edition-provided notes/PDFs and playing matched audio, with search, organization, bookmarks and review controls. This public repository contains application code and synthetic tests only.

Read [START_HERE.md](START_HERE.md), [SETUP.md](SETUP.md) and [PUBLICATION_STATUS.md](PUBLICATION_STATUS.md). Edition notes, PDFs, audio, timing data and the source-derived study-guide preview are excluded. Historical edition-specific narration/alignment generation scripts are also excluded. No complete edition or AI-generated output is supplied.
